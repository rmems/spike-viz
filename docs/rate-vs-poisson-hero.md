# Rate vs Poisson hero still

![Rate deterministic streaming vs Poisson stochastic raster](images/rate-vs-poisson.png)

This 2048 × 720 PNG is ready to copy into the axon-encoder wiki or README.
It paints checked-in Rust exports, not a Python encoder or synthetic replacement.
Both panels use the same time and neuron scales, with white marking **event
presence** rather than amplitude or normalized firing intensity. Neuron IDs run
from top to bottom; the horizontal span is 64 samples × 1 ms = 64 ms.
Each visible caption includes encoder behavior, seed, `dt_seconds`, N, T, and
the full axon-encoder commit. The PNG also carries a textual `Description`.

## Render from the checked-in exports

From the repository root after [installing spike-viz](../README.md#install):

```bash
python - <<'PY'
from spike_viz import render_rate_poisson_hero

render_rate_poisson_hero(
    "fixtures/axon-encoder/rate/shared_sine_v1",
    "fixtures/axon-encoder/poisson/shared_sine_v1",
    rate_mode="streaming",
    out_path="docs/images/rate-vs-poisson.png",
)
PY
```

The renderer requires full commit SHAs, `synthetic: false`, equal N/T/dt,
and identical finite `[T, N]` `stimulus.npy` arrays. Missing or incompatible
files raise `SpikeIOError`; there is no fallback. Rendering works on CPU and
does not require bloom, CUDA, matplotlib, or external font files.

`rate_mode` is mandatory because the export contract does not record batch
versus streaming behavior. Check the pinned exporter before choosing it.
Use `"batch"` only for an actual batch Rate export, never for these fixtures.

## Exact fixture source

Both `shared_sine_v1` cases come from axon-encoder 0.6.0 at
[`becb40d0c8722710677dabbf66d420a9c77f2eda`](https://github.com/Limen-Neural/axon-encoder/commit/becb40d0c8722710677dabbf66d420a9c77f2eda),
generated by
[`examples/export_spike_viz.rs`](https://github.com/Limen-Neural/axon-encoder/blob/becb40d0c8722710677dabbf66d420a9c77f2eda/examples/export_spike_viz.rs).

- [Constants and shared stimulus](https://github.com/Limen-Neural/axon-encoder/blob/becb40d0c8722710677dabbf66d420a9c77f2eda/examples/export_spike_viz.rs#L32-L59):
  64 steps, 8 channels, `dt_seconds=0.001`, seed `0x5EED_0001`
  (1592590337), deterministic mixed sine/ramp input.
- [Rate path](https://github.com/Limen-Neural/axon-encoder/blob/becb40d0c8722710677dabbf66d420a9c77f2eda/examples/export_spike_viz.rs#L86-L124):
  `drive` calls `RateEncoder::encode_step`, so this is **deterministic
  streaming**, not stochastic batch `encode`. The Rate seed is recorded
  provenance only; this path uses no RNG. Rate maps input 0–1 to 50–400 Hz.
- [Poisson path](https://github.com/Limen-Neural/axon-encoder/blob/becb40d0c8722710677dabbf66d420a9c77f2eda/examples/export_spike_viz.rs#L169-L191):
  `encode_rate_hz_step_with_rng` makes seeded stochastic draws in channel-major
  order, using `50 + 300 * stimulus[t][ch]` Hz (50–350 Hz).

**Same stimulus is not a parameter-matched rate experiment:** the Rust exporter
uses different rate mappings for these two encoders. The figure illustrates
deterministic streaming versus stochastic event placement; it does not establish
equal expected spike counts or a statistical comparison.

To regenerate the underlying exports from the exact Rust source:

```bash
git clone https://github.com/Limen-Neural/axon-encoder.git /tmp/axon-encoder-hero
git -C /tmp/axon-encoder-hero checkout becb40d0c8722710677dabbf66d420a9c77f2eda
AXON_ENCODER_DIR=/tmp/axon-encoder-hero \
AXON_ENCODER_GIT_SHA=becb40d0c8722710677dabbf66d420a9c77f2eda \
  scripts/generate_fixtures.sh
```

This requires Rust/Cargo and Python with spike-viz installed. The script runs
the Rust exporter for all six fixture families, then packs its arrays through
`scripts/pack_axon_export.py`. Python only packages and validates those exports;
it does not re-encode the stimulus. See the [export contract](axon-encoder-export.md).
Finally rerun the render command above. Pixel-level text may differ across Pillow
versions; the spike data and provenance remain unchanged.
